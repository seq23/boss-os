# Outbound Email Map

Last verified 12 Oct 2026.

Question answered: "What controls all the emails going out from The Industry Guides and all side businesses? Is it a Mac launchd job only?"

Scope: Boss OS and the side businesses it runs, only. The fund's sending paths are not listed here; they live in the fund's own repo and never share a repo, a seat or a ledger with Boss OS.

## Answer

- **No. Of 21 live sending paths, 6 run from launchd on the Mac, 8 run in Cloudflare (4 on Worker crons, 4 on a form or purchase), 6 run on GitHub Actions schedules and 1 happens only inside a Claude session. 2 more look like senders but are switched off.**
- Mac-dependent (6): every Boss OS push email to you (task notices, repo-change results, YouTube comment watch, the KDP surface report and vault intake confirmations, from <name>@sequoiataylor.com via Resend) and the CI-sweep issues. All of them go to you, never to outsiders. A sleeping Mac delays them; it never sends anything late to a stranger.
- Cloud, Mac off or on (14): everything that reaches people outside: Monique's outreach for the five Industry Guides and four side businesses (Boss OS Worker, hourly, Gmail API as st@time-2-read.com), the Industry Guides lead forms (the five canonicals and the hub's function), ApprovalPrep and wedding-checklist purchase email, Creator Studios, A Player Mode, client properties, plus the Industry Guides' weekly search-outcome report and the How We Know and backlink-network issues on GitHub Actions.
- Session-only (1): the claude.ai Gmail connector, which sends as seq.taylor@gmail.com only while a Claude session (or a session cron) is open.

| Runs where | Paths |
|---|---|
| Mac launchd | 6 |
| Cloudflare Worker cron | 4 |
| Cloudflare on event (form, purchase) | 4 |
| GitHub Actions | 6 |
| Claude session only | 1 |
| Inert (looks like a sender, sends nothing) | 2 |

Not senders: Cloudflare Email Routing (hello@theindustryguides.com → cryptoclearr@gmail.com) is inbound only; Buffer is social.

## Method

- launchd: `launchctl list`, every plist in ~/Library/LaunchAgents and ~/bin/launchd (program and schedule); no crontab exists.
- Code: `git grep` on origin/main of every repo under ~/GitHub (plus ~/aplayer-mode, ~/bin) for Resend, Gmail send, SMTP, MailChannels, SendGrid, Postmark, Mailgun, nodemailer, send_email; workflows grepped for mail and issue creation.
- Cloudflare: wrangler.toml crons and email vars per repo; Pages secret names (not values) on two guides projects.
- Not read: live D1 switch state for Monique's outreach, Pages dashboard variables for the five guides lead forms, GitHub watch settings.
