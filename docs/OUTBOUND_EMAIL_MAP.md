## Answer

- **No. Of 31 live sending paths, 9 run from launchd on the Mac, 15 run in Cloudflare (8 on Worker crons, 7 on a form, purchase or button), 6 run on GitHub Actions schedules and 1 happens only inside a Claude session. 2 more look like senders but are switched off.**
- Mac-dependent (9): every Boss OS push email to you, all in one plain layout (src/shared/boss/mail/plain.mjs; Decide-first since 23 Oct 2026: a plain subject with no #tag, code or capitals, the first line saying what happened, "Decide (N)" with one-tap buttons or "Nothing to decide", then the sections, the employee's name once; a problem email is What happened → What we did → Status; job codes ride in a hidden header) and checked by the send-time gate in scripts/ops/notify.mjs (postEmployeeMail → mailGate: an email with a code, a command, an /api path, a PR number, a UTC time, a #tag, jargon, too much length, Decide not first, or a problem email missing what we did or its status is HELD — written to ~/.boss-os/held-mail and handed to Danielle as a fix job — never sent; npm run validate:email-plain).
