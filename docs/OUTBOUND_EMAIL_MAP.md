# Outbound Email Map

Last verified 12 Oct 2026.

Question answered: "What controls all the emails going out from The Industry Guides and all side businesses? Is it a Mac launchd job only?"

## Answer

- **No. Of 34 live sending paths, 14 run from launchd on the Mac, 12 run in Cloudflare (5 on Worker crons, 7 on a form, purchase or sign-in), 6 run on GitHub Actions schedules, 1 happens only inside a Claude session and 1 runs in an outside service (Twin). 3 more look like senders but are switched off.**
- Mac-dependent (14): every Boss OS push email to you (Monique, Simone and the other employees, from <name>@sequoiataylor.com via Resend), the scooter-watch reports, and the CI-sweep issues. All of them go to you or your own inboxes, never to outsiders. A sleeping Mac delays them; it never sends anything late to a stranger.
- Cloud, Mac off or on (18): everything that reaches people outside: Monique's outreach for the five Industry Guides and four side businesses (Boss OS Worker, hourly, Gmail API as st@time-2-read.com), Porter's partner email (West Peek OS Worker, every minute, Resend from os@westpeek.ventures), every site form and purchase email, Creator Studios, plus the Monday search report and How We Know issues on GitHub Actions.
- Session-only (1): the claude.ai Gmail connector, which sends as seq.taylor@gmail.com only while a Claude session (or a session cron) is open.

Not senders: Cloudflare Email Routing (hello@theindustryguides.com → cryptoclearr@gmail.com) is inbound only; HeyReach (8raise) is LinkedIn, not email; Buffer is social.

## Method

- launchd: `launchctl list`, every plist in ~/Library/LaunchAgents and ~/bin/launchd (program and schedule); no crontab exists.
- Code: `git grep` on origin/main of every repo under ~/GitHub (plus ~/aplayer-mode, ~/bin) for Resend, Gmail send, SMTP, MailChannels, SendGrid, Postmark, Mailgun, nodemailer, send_email; workflows grepped for mail and issue creation.
- Cloudflare: wrangler.toml crons and email vars per repo; Pages secret names (not values) on two guides projects.
- Not read: live D1 switch state for Monique's outreach, Pages dashboard variables for the five guides lead forms, Twin's dashboard, GitHub watch settings.
